# Vanilla entity atlases

These are the unmodified Mojang Bedrock sample textures used as **layout
templates** by `tools/content.py`. The generator recolours them and writes the
result into `resource_pack/textures/entity/`; these source files are not
included in the `.mcpack`.

Source: [Mojang/bedrock-samples](https://github.com/Mojang/bedrock-samples),
`resource_pack/textures/entity/`.

These files remain Mojang assets and are not relicensed by this project's MIT
licence. They are kept here only so the fan texture pack can be rebuilt
offline. See `LICENSE` for the full note.
